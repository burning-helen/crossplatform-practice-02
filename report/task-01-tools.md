# Задание 1. Классификация инструментальных средств

Дата проверки сведений: 15.10.2026.

В таблице рассматриваются инструменты разных категорий:
среды выполнения, виртуальные машины, системы сборки,
десктопные и мобильные фреймворки, WebView-обёртки
и средства контейнеризации.

Для каждого инструмента указаны назначение, механизм переносимости,
лицензия, версия и дата выпуска. Сведения о релизах проверяются
по официальным источникам.

Для инфраструктурных инструментов в графе примера указывается
проект, использующий инструмент, или пример его применения:
система сборки и контейнерная среда сами по себе не являются
фреймворками создания интерфейса.

## Различие Electron и Tauri

Electron включает Chromium и Node.js в поставку приложения.
Это даёт разработчику единый браузерный движок на поддерживаемых
настольных ОС, но увеличивает объём поставляемых компонентов.

Tauri использует системный WebView и нативную часть приложения.
Отсутствие встроенного браузерного движка позволяет уменьшить
размер поставки, однако требует учитывать особенности и зависимости
WebView на каждой целевой платформе.

Точный размер дистрибутива и потребление памяти нельзя определить
только по названию фреймворка: для корректного сравнения необходимы
сопоставимые приложения, настройки сборки и условия измерения.
