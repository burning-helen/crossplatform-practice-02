## Цель работы

Изучить современные инструменты кросс-платформенной разработки,
подготовить рабочее окружение, исследовать структуру готового
проекта и выполнить сравнительный анализ технологий.

Вариант № 4 — Electron и Tauri 2.

Сценарий: десктопный клиент корпоративного мессенджера
для Windows, macOS и Linux, включая Astra Linux.
Основные требования — небольшой размер дистрибутива и безопасность.
